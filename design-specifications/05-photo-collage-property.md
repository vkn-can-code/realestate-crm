# DESIGN SPECIFICATION 05: PHOTO COLLAGE PROPERTY

- **TEMPLATE NAME**: Photo Collage Property
- **BUSINESS PURPOSE**: Showcase multiple room highlights (exterior, kitchen, pool, master suite) in a single visual graphic.
- **TARGET AUDIENCE**: Families, luxury buyers interested in interior finishes.
- **PRIMARY PLATFORM**: Instagram Portrait (4:5 / 1080x1350)
- **SECONDARY PLATFORM**: Facebook Post (1.91:1 / 1200x630)
- **VISUAL EMOTION**: Comprehensive, Inviting, Detailed, Complete
- **ART DIRECTION**: Multi-frame asymmetric photo grid. 1 Large Hero Exterior frame on left/top + 3 smaller inset room frames (Kitchen, Pool, Master Bedroom) on right/bottom separated by crisp 4px white gutters.
- **LAYOUT ARCHITECTURE**: 4-photo asymmetrical grid composition with centered floating glass specs pill in middle gutter.
- **IMAGE COMPOSITION**: 1 Exterior + 1 Kitchen + 1 Living Room + 1 Bath/Pool photo.
- **TEXT HIERARCHY**:
  - Title: `Inter` (36px, ExtraBold 800, Dark Slate `#0F172A`)
  - Center Pill Badge: `Inter` (14px, Bold 700, White on Glass)
- **COLOR STRATEGY**: Off-White Slate (`#F8FAFC`), Deep Slate (`#0F172A`), Electric Blue (`#3B82F6`).
- **CTA STRATEGY**: "EXPLORE ALL 24 PHOTOS".
- **PROPERTY DATA USED**: Title, Location, Price, 4 Property Photos (Exterior, Interior, Kitchen, Amenities).
- **UNIQUE DESIGN CHARACTERISTICS**: 4-photo asymmetrical grid composition showing interior + exterior features simultaneously.
- **WHY THIS TEMPLATE IS DIFFERENT FROM THE OTHER 29**: It is the only 4-photo collage layout displaying multiple property areas in one unified grid.

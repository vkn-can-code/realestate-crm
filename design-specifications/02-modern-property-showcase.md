# DESIGN SPECIFICATION 02: MODERN PROPERTY SHOWCASE

- **TEMPLATE NAME**: Modern Property Showcase
- **BUSINESS PURPOSE**: Capture attention for contemporary, urban, and modern architectural single-family homes.
- **TARGET AUDIENCE**: Millennial buyers, tech professionals, urban movers.
- **PRIMARY PLATFORM**: Instagram Square (1:1 / 1080x1080)
- **SECONDARY PLATFORM**: Facebook Post (1.91:1 / 1200x630)
- **VISUAL EMOTION**: Crisp, Modern, High-Energy, Professional
- **ART DIRECTION**: Modern Swiss design style. Ultra-clean white canvas (`#FFFFFF`) with stark charcoal text (`#0F172A`), electric blue accents (`#2563EB`), and a floating center crop photo frame with 24px rounded corners.
- **LAYOUT ARCHITECTURE**: Floating center image container (`960x620px`) with drop shadow (`0 20px 40px rgba(0,0,0,0.15)`), top pill badge, and a horizontal 3-column spec ribbon below.
- **IMAGE COMPOSITION**: Modern exterior or open-concept living room photo with high natural lighting.
- **TEXT HIERARCHY**:
  - Title: `Inter` (38px, ExtraBold 900, Charcoal `#0F172A`)
  - Specs Ribbon: `Inter` (15px, Bold 700, Dark Blue `#1E3A8A`)
  - Price Tag: `Inter` (34px, Black 900, Royal Blue `#2563EB`)
- **COLOR STRATEGY**: Pure White (`#FFFFFF`), Royal Blue (`#2563EB`), Slate Gray (`#64748B`).
- **CTA STRATEGY**: "VIEW FULL GALLERY →" blue button.
- **PROPERTY DATA USED**: Title, Price, Location, Beds, Baths, Sqft, Primary Photo.
- **UNIQUE DESIGN CHARACTERISTICS**: Clean white background with drop-shadow float container and high-contrast blue spec pills.
- **WHY THIS TEMPLATE IS DIFFERENT FROM THE OTHER 29**: It is the only light-mode Swiss layout using drop-shadow floating canvas cards and 3-column horizontal spec metrics.

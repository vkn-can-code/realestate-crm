# DESIGN SPECIFICATION 17: MEET THE AGENT

- **TEMPLATE NAME**: Meet Your Realtor Spotlight
- **BUSINESS PURPOSE**: Build personal brand, establish agent authority, and create human connection with clients.
- **TARGET AUDIENCE**: Home buyers and sellers seeking a trusted local advisor.
- **PRIMARY PLATFORM**: Instagram Square (1:1 / 1080x1080)
- **SECONDARY PLATFORM**: LinkedIn Post (1.91:1 / 1200x627)
- **VISUAL EMOTION**: Personal, Trustworthy, Accessible, Professional
- **ART DIRECTION**: Executive magazine profile style. Left 40% = Circular agent portrait with gold border ring, Right 60% = Bio summary, license number, specializations, and contact button.
- **LAYOUT ARCHITECTURE**: Horizontal split card with agent headshot frame on left and bio text column on right.
- **IMAGE COMPOSITION**: High-quality agent studio headshot or portrait.
- **TEXT HIERARCHY**:
  - Agent Name: `Playfair Display` (42px, Bold 800, White `#FFFFFF`)
  - Role Title: `Inter` (16px, SemiBold 600, Indigo `#818CF8`)
  - Bio Paragraph: `Inter` (15px, Regular 400, Light Gray `#CBD5E1`, Line Height 1.5)
- **COLOR STRATEGY**: Midnight Indigo (`#1E1B4B`), Electric Indigo (`#6366F1`), Soft Lavender (`#E0E7FF`).
- **CTA STRATEGY**: "CALL DIRECT / SCHEDULE CONSULTATION".
- **PROPERTY DATA USED**: Agent Headshot, Agent Name, License #, Phone, Bio, Speciality Neighborhoods.
- **UNIQUE DESIGN CHARACTERISTICS**: Circular portrait avatar with gold border ring and two-column executive bio layout.
- **WHY THIS TEMPLATE IS DIFFERENT FROM THE OTHER 29**: Dedicated human portrait profile layout focused entirely on agent biography and credentials.

# DESIGN SPECIFICATION 07: PROPERTY FEATURES SHOWCASE

- **TEMPLATE NAME**: Property Features Showcase
- **BUSINESS PURPOSE**: Highlight specific high-value property features (smart home automation, chef's kitchen, wine cellar, heated pool).
- **TARGET AUDIENCE**: Buyers seeking premium lifestyle amenities.
- **PRIMARY PLATFORM**: Instagram Portrait (4:5 / 1080x1350)
- **SECONDARY PLATFORM**: Facebook Post (1.91:1 / 1200x630)
- **VISUAL EMOTION**: Informative, Premium, Feature-Rich
- **ART DIRECTION**: Split 50/50 vertical layout. Left 50% = Hero Photo, Right 50% = 4 Key Feature Pill Cards with vector icon indicators.
- **LAYOUT ARCHITECTURE**: Vertical split layout with left image and right feature breakdown list.
- **IMAGE COMPOSITION**: Interior detail photo (Chef's kitchen or master bathroom).
- **TEXT HIERARCHY**:
  - Main Title: `Inter` (34px, Bold 800, White `#FFFFFF`)
  - Feature Pills: `Inter` (16px, SemiBold 600, White on Glass)
- **COLOR STRATEGY**: Deep Navy (`#0F172A`), Cyan Blue (`#06B6D4`), Soft Blue (`#E0F2FE`).
- **CTA STRATEGY**: "SCHEDULE AMENITY TOUR".
- **PROPERTY DATA USED**: Title, Location, Price, Key Amenities, Interior Photo.
- **UNIQUE DESIGN CHARACTERISTICS**: Vertical 50/50 split with icon feature checklist cards.
- **WHY THIS TEMPLATE IS DIFFERENT FROM THE OTHER 29**: It is the only template with a 50/50 vertical split feature checklist.

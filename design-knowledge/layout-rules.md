# Layout Rules & Composition Systems

## 1. Layout Families
- **Full-Bleed Hero Overlays**: Image occupies 100% width and 60-70% height with bottom dark gradient scrim overlaying text.
- **Split Frame (50/50 or 60/40)**: Hero exterior image on the left, interior feature photo on the right, or top photo / bottom info card.
- **Card-in-Card Composition**: Outer dark/gradient canvas containing a floating frosted glass inner card with rounded corners (`borderRadius: 24-36px`).
- **Architectural Grid System**: Clean multi-column layout with 2px hairline dividers and generous white space.

## 2. Multi-Format Aspect Ratio Adaptation
- **Instagram Square (1:1 / 1080x1080)**: Balanced vertical stack with central focal point.
- **Instagram Portrait (4:5 / 1080x1350)**: Extended hero photo area allowing 30% more visual space for interior highlights.
- **Instagram Story (9:16 / 1080x1920)**: Vertical orientation. Place key titles and CTA in the middle safe zone (avoiding top Instagram UI header and bottom swipe-up bar).
- **Facebook / LinkedIn (1.91:1 / 1200x630)**: Horizontal orientation. Side-by-side split layout (Left: Image, Right: Specs & CTA).
